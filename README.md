# TN Nalavaariyam Frontend

Vite + React + Tailwind SPA scaffold for the TN Nalavaariyam rebuild.

## Scripts

- `npm run dev` - start local development server.
- `npm run build` - production build.
- `npm run preview` - preview production build.
- `npm run lint` - run oxlint.

## Notes

- Public marketing pages are scaffolded from the `tnnalavariyam.com` reference.
- Application dashboard/form placeholders are scaffolded from the six-form analysis.
- Static reference images live in `public/assets/images`.
